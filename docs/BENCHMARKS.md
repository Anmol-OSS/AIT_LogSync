## 2. Full worker chain

Archive (write-first) → Merkle leaf (fsync per batch) → WASM tokenize → normalize with per-field provenance → round-trip gate → SQLite index → Parquet lake, plus signed tree heads with RFC 3161 timestamps every 2 s.

- **2,238 events/s per core** (18000 events in 8.04 s)
- Cores needed for the deck's 1 B events/day (11.6k EPS average): **5.2**; for the 3× burst (34.7k EPS): **15.5**
- Slide 4's 139,654 events/s covers only parse → serialize → SHA-256; the difference is the evidence work (archive, Merkle, provenance for ~20 fields per event, index, lake).

## 3. Verification latency (re-derive from archived bytes)

200 random events, all five checks: median **1.6 ms**, p95 **3.6 ms** per event. All 200 verified.

## 4. Raw archive

- 5,721,803 raw bytes received, 5,721,803 unique after content addressing, **653,670 on disk** sealed with gzip-6 → **8.8× smaller** (synthetic logs repeat more than live traffic: treat as an upper bound).
- Average event: 318 bytes.

## 5. Round-trip gate per family

| family | clean lines accepted | trailing garbage blocked | truncated lines blocked |
|---|---:|---:|---:|
| cisco_asa | 3000 / 3000 (100.0%) | 500 / 500 | 500 / 500 |
| fortigate | 3000 / 3000 (100.0%) | 500 / 500 | 500 / 500 |
| panos | 3000 / 3000 (100.0%) | 500 / 500 | 491 / 500 |
| checkpoint_cef | 3000 / 3000 (100.0%) | 0 / 500 | 453 / 500 |
| checkpoint_leef | 3000 / 3000 (100.0%) | 0 / 500 | 482 / 500 |
| suricata | 3000 / 3000 (100.0%) | 500 / 500 | 500 / 500 |

What the gate guarantees: every byte is either grammar, inside a captured field, or the event is blocked - and every declared check and transform holds. What no parser can know from bytes alone: text appended to a *free-text* last field (a CEF `msg`, a LEEF rule name) is indistinguishable from a longer value, and a line cut exactly at a field boundary looks like a shorter valid record. Those events are accepted with the bytes they actually contain - nothing is invented or dropped - and the raw line stays archived and provable either way.
